With a custom css addon you can change the look of websites however you want :D
So I started making custom themes for Tumblr

You may use these and/or build off of them. The images in this repository are free for personal use for this purpose

Also since these are for me, they don't follow accessibility contrast guidelines. I like my stuff low-contrast cos I can see it's easier on the eyes for me

Tutorial if you don't want to do too much coding yourself:

If you want to build your own thing, pick the Easy Customization file. Otherwise, pick one of my pre-built ones.
On top, you have the choice between two background image styles, delete the one you don't need (full-width or pattern).
Below, you have a section where you can input your own color variables. I already sorted them so everything that I think makes sense to be the same color is already using the same variables, so unless you want more color variety you can leave everything below the first section alone. You need hex codes and one RGB code, you can for example pick those here: https://htmlcolorcodes.com/
Below the colors, you can enter a font. On desktop, you can use all the fonts available in the profile section on tumblr (that you can use for your title). Two-word font names need to go in "", one-word fonts don't.

Hope this helps, have fun customizing
